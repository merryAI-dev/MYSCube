현재 시안에는 공용 관리자도 계정을 연결할 수 있지만, 역할 반영은 관리자 자신의 명부 연결을 요구하는 제한이 남아 있어요. 가이드가 이 조건을 해결하지는 않습니다.

역할 반영이 막혔다면,
연결부터 다시 하지 않아요.

연결은 유지됐는지, 역할은 반영됐는지 따로 확인해요. 관리자 자격이 부족하면 조건을 충족한 승인 담당자에게 이어서 요청합니다.

성공을 가정해 완료 화면으로 넘기지 않아요. 실제 업무 접근과 프로젝트 담당 배정도 별도로 확인해야 해요.

멈춘 지점에서 이어가세요

이럴 때는 어떻게 하나요?

팝업을 닫았어요. 처음부터 해야 하나요?

가입 안내의 회원정보 작성 버튼으로 이어갈 수 있어요. 현재 시안은 같은 탭에서 초안을 유지합니다. 운영의 기기 간 복원은 서버 연동 후 검증이 필요해요.

저장됐는데 업무 화면이 안 열려요.

회원정보 저장은 권한 승인이 아니에요. 관리자에게 명부 연결과 역할 승인 상태를 확인해 주세요. 이 시안에서는 운영 접근이 생기지 않습니다.

명부 후보가 없거나 여러 명이에요.

이름이 비슷하다고 임의로 연결하지 않아요. 관리자가 검증된 이메일과 기존 기록의 중복·불일치를 해결한 뒤 상태를 새로 확인합니다.

저장 결과를 확인하지 못했다고 나와요.

입력 내용을 유지하고 ‘저장 상태 다시 확인’으로 결과를 조회해요. 결과가 불명확한 상태에서 같은 쓰기를 반복하지 않습니다. 운영 저장/재조회는 아직 연결되지 않았어요.

이 가이드대로 지금 운영에서 가입할 수 있나요?

아직 아닙니다. 로컬 합성 프로토타입을 설명하는 개편안이에요. 신규 계정의 본인 정보 저장 API와 접근 조건, 관리자 역할 조건이 실제로 연결·검증된 뒤 운영 가이드로 전환해야 합니다.
