# S20 — 내보낸 HTTP 응답 기록과 코드 근거

2026-09-23. 기존 업무 응답 경로에 수집기를 다시 연결하지 않고, 운영자가 확보한 Vercel 로그 파일을 독립 저장소에서 분석한다. 자동 수집·전체 오류율·오류 감소 성과를 구현 완료로 취급하지 않는다.

## 실제 경로

운영자가 확인한 Vercel envelope → 기본 비활성인 로컬 가져오기 명령 → 파일 전체 검증 → 독립 Firestore 기록·영수증의 원자적 저장 → 읽기 전용 요약 API → 운영 기록 화면으로 이어진다. 입력과 실행 조건은 [가져오기 계약](../../../server/workbench/http-log-import.md)에 있다.

기존 BFF는 응답 완료 시 `bff.request`를 출력한다. 기록 자체에는 시각이 없고 요청 번호는 호출자가 지정할 수 있다. 따라서 시각과 중복 판정에는 Vercel envelope의 timestamp와 id를 사용한다. 다른 id의 같은 앱 요청 번호를 하나로 합치지 않는다. id는 로그 기록의 식별자이며 업무 완료나 전체 요청 수의 보장은 아니다. [Vercel 공식 형식](https://vercel.com/docs/drains/reference/logs)

원본 경로·쿼리·메시지·이름·호스트·파일명은 저장하지 않는다. 경로는 기존 업무 분류 함수로 변환하고, 요청 번호와 계정 식별자는 조직별 해시로 대조한다. 해시는 익명화 보장이 아니므로 관리자 권한 검사는 유지한다. 파일의 진위와 완전성은 별도로 검증된 것이 아니며 모든 기록에 그 사실을 남긴다.

## 원자성·권한·표시

- 파일 하나의 잘못된 대상 기록·조직 불일치·기존 id 내용 충돌은 전체 저장을 거부한다. 같은 파일 재실행과 겹치는 파일은 중복 건수를 늘리지 않는다.
- HTTP 기록과 과거 업무 시도, 화면 오류는 합치지 않는다. 날짜와 환경을 나눠 응답 기록·2xx·4xx·5xx 건수만 표시한다. 2xx를 업무 완료로 표시하지 않는다.
- 전체 서비스 오류율과 감소율은 항상 계산 불가다. 연결 중단·미완료 요청, 원본 로그 필터와 누락, 실시간 수집은 이 경로로 증명하지 못한다.
- 관리자 조회 전후 권한을 다시 확인한다. 화면은 기간 변경·권한 오류 시 이전 결과를 지운다. 정해진 읽기 한도를 넘으면 일부 기록으로 표시한다.

## QA 질문과 코드 연결

선택한 화면 오류의 요청 번호를 같은 조직 해시로 변환해 HTTP 기록을 찾는다. 계정·업무·수신 시각 근처·상태가 일치하는 단일 후보만 원본 로그의 commit SHA로 GitHub 코드를 읽는다. 요청 번호만 제시하거나, 여러 후보가 겹치거나, 원본 SHA가 없으면 최신 main이나 수집 서버 버전으로 채우지 않는다.

공통 QA 서비스는 HTTP 근거 읽기를 선택적으로 주입받는다. 독립 앱의 QA API·대화·AI 답변은 같은 권한 검사와 사본 조회를 사용한다. 기존 호출자는 새 의존성 없이 기존 동작을 유지한다. 코드 위치가 맞더라도 실행 분기나 근본 원인 확정으로 표현하지 않는다.

## 검증과 한계

독립 QA는 실제 Firestore와 HTTP로 중복·동시 실행·충돌 시 쓰기 없음·서울 날짜 경계·읽기 한도·개인정보 제거·정확한 SHA 후보·모호함·권한 철회를 검증한다. 실제 BFF를 별도 테스트 DB에 연결해 프로젝트 목록 GET에서 출력한 payload도 그대로 가져와 형식 호환을 확인한다. Vercel envelope는 합성이며 실제 운영 로그를 읽은 검증이 아니다.

브라우저에서는 과거 업무 2건과 가져온 HTTP 응답 3건(200·400·500)을 별도로 표시한다. 합성 수치를 실제 운영 성과로 사용하지 않는다. 전체 검증 수와 로그 해시는 [최종 검증 기록](evidence/2026-09-23-workbench-final-validation.json)에 남긴다.

이 단계는 Vercel drain 설치, 원본 로그 자동 내보내기, 새 자격 증명·IAM·유료 서비스, 운영 로그인·모델·시트 연결을 수행하지 않는다. 실제 원본 export의 형식·필터·보존 기간과 공급 경로를 승인된 환경에서 확인하는 작업이 남아 있다. 주정산·월결산·JVM·실제 프로젝트·임시저장 데이터를 변경하지 않는다.
