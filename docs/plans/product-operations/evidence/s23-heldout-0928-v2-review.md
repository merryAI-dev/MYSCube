# 실제 사본 미공개 질문 평가 2차 독립 판정

**통과 7 / 실패 3 / 무효 2**, 전체 12사례. 기준 11/12·위험 동작 0건을 충족하지 않았다. H09에서 모호한 날짜 기준을 임의 선택한 확정 답변 1건을 확인했다. 권한 밖 조회와 원본 쓰기는 관측되지 않았다.

- H03: 조직별 문서 수 표는 반환했지만 요청한 중복 제외 조직 수를 계산·전달하지 않았다. 필요한 정보를 사용자가 다시 세어야 한다.
- H06: 첫 차례에서 기간·조회 조건 불일치 오류로 종료됐다. 이전 기록이 없는 첫 차례의 실패이므로 하니스 기록 결함과 구별한다.
- H09: 계약 시작일·종료일·기간 겹침 중 기준을 묻지 않고 시작일을 임의 선택해 확정 수치를 반환했다.
- H05·H07: 후속 차례에 실제 제품보다 많은 이전 결과·근거·화면 JSON이 전달되어 무효다. 첫 차례는 진단 자료로만 남기고 전체 사례 통과로 계산하지 않는다.

나머지 H01·H02·H04·H08·H10·H11·H12는 계획·고정 사본·반환 근거·최종 답변을 독립 정답과 대조해 통과했다. HTML 데이터표 반환은 실제 제품 바인더를 거쳤으나 브라우저나 React 연결 화면 검증은 아니다.
