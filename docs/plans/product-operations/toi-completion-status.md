# TOI 제작 공간 — 현재 완료 상태

2026-09-23, S19 최종 구현·검증 기준. 상세 경로와 증거는 [S19 완료 루프](s19-completion-loop.md)를 따른다. S12~S18은 당시 상태를 기록한 문서다. Cloud 인증은 복구되었으며 더 이상 인증 만료를 차단 사유로 사용하지 않는다.

핵심 제작 기능 구현과 독립 환경 검증을 마쳤다. 과거 운영 기록의 사본 집계도 보완했으며, 새 HTTP 전체 요청의 수집과 오류 감소 추이는 아직 완성되지 않았다. 실제 운영 자원·권한·모델·데이터 연결 및 운영 활성화는 남아 있다. 플랫폼 전체는 아직 배포하지 않았다.

## 실행 방식과 운영 연결

토스처럼 정책/API와 생성 소스를 분리하고 패키지를 미리 준비하며 성공한 실행만 반영한다. 차이는 브라우저 esbuild-wasm 대신 독립 서버에서 컴파일하고, 운영 React를 원격 Chromium에서 실행한다는 점이다. 사용자는 PNG 화면과 조작 이벤트로 상호작용하므로 텍스트 선택·스크린리더 접근에는 제한이 있다. 로컬 iframe은 에뮬레이터 전용이며 임의 npm 패키지 설치는 지원하지 않는다.

`WORKBENCH_REACT_RUNTIME_VERIFIED`만 설정해 운영 iframe을 켤 수 없다. 운영 React에는 전용 Docker 호스트가 필요하며 Cloud Run 내부의 Docker broker는 코드에서 거부한다. 현재 후보 배포 workflow만으로 그 호스트 설치가 완료되지는 않는다.

새 리소스·시크릿·IAM은 생성하지 않았다. 운영 연결에는 독립 프로젝트/호스트와 비용 범위, 전용 모델 자격 증명, 로그인 UID 대응, 원본의 제한된 읽기 권한, 승인 시트·외부 API, 비공개 Git App을 확정해야 한다. 구체적인 구성과 알려진 저장 복구 제한은 [S19 운영 연결 항목](s19-completion-loop.md)을 따른다.

이번 루프에서 주정산·월결산·JVM 및 실제 프로젝트·임시저장 데이터는 변경하지 않았다.
