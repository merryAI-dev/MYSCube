# S10 개인화 CEO 인사이트 어드민

## 완료할 업무
`내 업무 페이지`의 조회할 자료에서 `CEO 인사이트 · 여러 지표 구성`을 선택한다. 지표 추가·삭제·순서·제목·너비·기간·필터·표현을 변경하고 저장한다. 재접속 시 구성과 버전을 읽고, 이전 구성 복원은 새 버전을 만든다.

고정 자료 소스와 화면 구성을 분리한다. 등록 지표는 현금흐름 반영 현황, 저장·제출·승인 품질, 구성원 서비스 안내다. 최대 6개 위젯을 조합한다. 키워드 구성 기능은 규칙 기반임을 명시하며 지원하지 않는 예측을 만들지 않는다. 선택적 모델 제안도 같은 엄격한 스키마를 통과해야 한다.

## 지표 계약
| 지표 | 근거 | 오해 방지 |
| --- | --- | --- |
| 현금흐름 | 기존 JVM 읽기 port의 반영 자료 | 계약금액을 현금으로 치환하지 않음. 미기록/실패/직접 0 구분. 현재 은행 잔고가 아님 |
| 운영 품질 | 신규 관측 업무 시도·서버 결과 | 시스템 오류/관측 업무 시도. 전체 무손실 분모가 아니며 과거 오류 건수와 섞지 않음 |
| 구성원 안내 | 운영자가 공개한 사건 필드 | 내부 근거·개인정보는 공개 안내에 섞이지 않음 |

현금흐름 보고는 권한 내 사업을 10개씩 최대 5페이지 읽는다. 25초 조회 예산과 50개 탐색 한도에서 멈추면 부분 자료임을 표시한다. 사업별 시각이 달라 원자적 전사 결산으로 부르지 않는다. 이전 페이지 성공 자료는 유지하고 권한 변경 시 전체 결과를 버린다. 주정산·월결산 처리 코드는 변경하지 않는다. Firestore의 모든 호출이 AbortSignal을 지원하는 것은 아니므로 25초를 HTTP 응답 시간의 절대 상한이라고 보장하지 않는다.

## 저장·권한
기존 개인 페이지 저장 경로, CAS 버전, 변경 이력, 복원을 재사용한다. schemaVersion1 단일 페이지는 그대로 읽고 schemaVersion2 위젯 구성을 추가한다. 저장물은 화면 구성이고 사업 데이터 사본이 아니다. CEO라는 이름으로 권한을 추가하지 않으며 기존 역할을 적용한다. 운영 지표는 관리자만 읽는다.

편집 중 이전 미리보기를 최신이라고 표시하지 않는다. 새 미리보기 반영 전 이전 구성 안내와 조작 차단을 적용한다. 계정 변경 시 프레임·자료를 초기화한다.
