## 사용자 연결

새로고침 후 ‘업무 만들기 → 연결 자료’에서 사용할 API를 선택하면 다음 대화 요청에 해당 API ID·버전이 전달된다. 등록만으로 기존 화면의 API 선택이나 저장 버전을 바꾸지 않는다. 실제 로그인된 사용자 브라우저 연결을 확보하지 못했으므로 운영 UI 선택 완료를 주장하지 않는다.

## 실시간 연결과 구분

운영 서버의 외부 endpoint 설정과 전용 인증 설정은 모두 비어 있음을 값 노출 없이 확인했다. 이 작업은 기존 사업 사본을 화면용 API로 등록한 것이며, MYSCube 실시간 BFF나 입금·매출·주정산 API 연결은 아니다. 기존 BFF는 Firebase 사용자 인증을 검증하므로 운영자 자격 증명을 재사용하거나 임의 헤더로 대신 연결하지 않았다. 금액·정산 자료를 ‘0’으로 채우지 않고 ‘확인 필요’로 안내하도록 API 설명에 명시했다. 실제 생성 화면의 표현은 별도 검증이 필요하다.
