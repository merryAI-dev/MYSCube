# 연도별 금액 확인 안내·합계수익률 수정 후보 검증

- 범위: 프로젝트 등록/수정 및 승인 문서의 금액 표시. 운영 데이터, JVM, 주정산/월결산 변경 없음.
- 기준: release804 조사에서 수집한 2026-09-21 16:23:49–57 KST 읽기 전용 snapshot. 신규 운영 상태를 주장하지 않음.
- 변경: 합계수익률은 계약기간의 모든 연도에 확인된 계약금액·수익이 있을 때만 계산. 분모 0은 계산 불가. 누락된 연도와 계약금액·매출 부가세·수익·실비(원가)·지원금을 구체적으로 안내. 직접 입력한 0원은 유효하고, 확인되지 않은 0원과 음수는 확정 금액으로 취급하지 않음. 표시 함수는 원본 금액·입력 여부·입금계획을 변경하지 않음.

## 별도 관찰

모비스 승인 문서의 저장된 상단 총실비·총지원금은 top-level 입력 플래그에 따라 0원으로 표시되나 연도별 같은 항목에는 확인 기록이 없다. 이번 연도별 안내가 차이를 드러낸다. 담당자 결정에 따라 공유 안내에 “표시된 기존 저장 합계가 있어도 연도별 입력이 완료된 것은 아닙니다. 계약서와 대조해 아래 항목을 확인해 주세요.”를 추가했다. 저장 총액을 강제 재계산하지 않고 연도별 미확인 항목을 분명히 구분한다. 해당 원본 금액이나 입력 플래그는 수정하지 않았다.

임시 하네스가 포함된 타입 검사에서는 하네스 자체 타입 오류가 있어 전체 TypeScript 통과로 보고하지 않는다. 관련 제품 파일의 타입 오류는 검출되지 않았으나 최종 저장소 전체 게이트는 루트 에이전트에서 별도 수행한다. 배포 완료 보고가 아닌 로컬 수정 후보 검증이다.
