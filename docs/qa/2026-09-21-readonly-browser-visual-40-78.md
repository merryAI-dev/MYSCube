# 실제 컴포넌트 읽기 전용 시각 검증 — 프로젝트 인덱스 40~78

## 독립 판정 기준

이 검증은 운영에서 읽은 고정 자료를 로컬 실제 입력/승인 컴포넌트로 렌더링한 결과를 검토한다. 운영의 인증·네트워크·저장·승인 성공을 증명하지 않는다. DOM에 값이 있다는 사실과 사람이 읽을 수 있게 화면에 표시된다는 사실을 별개로 판정한다.

## 현재 범위

39개 프로젝트(인덱스 40~78)를 담당한다. 번호는 캡처 manifest 정렬 기준으로 확정하며, 기존 운영 승인 목록 인덱스와 같은 번호로 간주하지 않는다. 생성된 원본 크기 이미지를 직접 열어 본 뒤 프로젝트별 결과를 추가한다. 캡처 생성 전에는 시각 통과로 기록하지 않는다.
