### 남은 표시 문제

링크가 정상 표시되는 승인 슬롯에서도 맨 오른쪽 **원문** 열은 `해당 없음`으로 나온다. 중앙의 URL은 정상 클릭 가능하고 데이터 누락은 아니지만, 검토자가 미제출로 오해할 수 있는 표현이다. 링크 제출일 때 `링크 열기` 또는 중복 안내 생략이 적절하다. 이번 QA는 제품 수정 없이 발견 사항만 전달했다.

과거 제출본의 `선택·미제출` 표시와 새 편집기의 `제출 또는 해당 없음 필수` 표시는 정책 시점이 다르다. 이를 같은 문서의 값 불일치로 단정하지 않되, 과거 문서임을 분명히 안내하는 편이 좋다.
