# 프로젝트 승인 항목별 배지 QA

## 범위와 데이터 경로

승인 목록의 제출 요청 payload/proposedSnapshot과 문서의 동일 제출본을 공통 resolver로 표시한다. 기존 첨부 슬롯 판정을 UI에서 platform helper로 옮겨 Google 링크, 해당 없음, 추후 제출 판정을 재사용한다. 문서 조회 후 BFF readiness와 파일 미리보기 오류를 추가 진단으로 사용한다. 저장·승인 정책이나 API 권한은 바꾸지 않는다.

- 양식 1: 이전 양식. 버전 없음: 양식 버전 미기록. 알 수 없는 버전: 양식 버전 인식 불가.
- 명시적으로 빈 첨부: 항목명 + 미제출. 항목 기록 자체 없음: 제출 기록 없음.
- 첨부 메타데이터만 있고 저장 위치/다운로드 주소 모두 없음: 재첨부 필요. 파일 자체가 삭제됐다는 뜻으로 안내하지 않는다.
- 서버/미리보기 조회 실패: 조회 실패. 미제출·재첨부로 추측하지 않는다.
- v2 등록의 게시 완료 상태를 목록에서 확정할 수 없으면 첨부 상태 미확인. BFF가 처리 중으로 확인한 경우만 첨부 준비 중.
- 금액이 실제로 비어 있으면 연도·항목별 미입력. 저장된 금액이 있지만 입력 여부가 미확인인 경우 입력 기록 확인. 직접 입력한 0원은 정상.
- 양식 구분과 저장 버전(requestVersion)은 독립이다. 현재 프로젝트 값을 과거 제출본에 채우지 않는다.
