# 배포 후 표시·보완 경로 개선 QA 단계 기준

2026-09-21. 사용자 승인 범위: 연간 재무/입금/합계의 입력 상태 일치, 링크·해당 없음·구형 미기록 구분, 기존 상태·금액 문제를 담당자가 확인하고 수정 제출할 수 있는 경로. 업로드 확대 및 주정산·월결산·JVM은 이 검증 범위에서 제외한다. 운영 값 자동 수정은 금지한다.

## 1. 의도와 실제 데이터 경로

금액은 같은 프로젝트 이름만 비교하지 않고 **프로젝트 ID·요청 ID·요청 버전·필드 경로**를 기준으로 비교한다. 실무자 개인 초안과 조직장 제출본은 다른 객체일 수 있다.

- 실무자: 개인 초안 원문/첨부 참조 → Portal 변환 → Wizard 금액 입력 상태 → 임시저장 → 최종 제출 snapshot.
- 조직장: 같은 request의 payload/proposedSnapshot → 승인 GET/readiness → dossier/연도 표/입금 표/총계.
- 상태 보완: 현재 저장 상태 확인 → 사용자가 의도한 상태를 선택한 개인 초안 → 최종 제출 → 승인 완료 시 원장 반영. 단순 읽기·경고 표시·초안 작성만으로 원장 상태가 바뀌면 FAIL.
- 파일: 저장 링크/파일 참조/명시적 미제출 사유/키 부재 → 동일 슬롯의 내용과 원문 동작. 필드 부재를 “사용자가 해당 없음 선택”으로 만들면 FAIL.

## 2. 승인 차단 정책의 권고

기존 승인 요청에 새 필수 요건을 소급 적용하지 않는 원칙을 유지한다. 입력 증거가 없는 과거 0, 상태가 실제 업무와 같은지 알 수 없음, 기록이 없는 파일은 구체적 **확인 경고**로 알린다. 자동 값 보정·일괄 반려·일괄 승인 차단은 하지 않는다.

기존 버전 충돌·권한·실제 첨부 확인 오류 차단은 유지한다. 완전히 기록된 금액의 산술 불일치를 새 차단 조건으로 만들 경우에는 GET readiness와 POST 승인 트랜잭션에 **같은 조건**이 있어야 하고 실제 결재 정책 변경임을 분명히 해야 한다. 화면 버튼만 막는 조치는 PASS가 아니다. 현재 `snapshotSchemaVersion:1`은 새 완전성 정책 통과를 증명하는 마커가 아니므로 이를 기준으로 과거/신규 필수 검증을 추정하지 않는다.

## 3. 구현 단계 통과 기준

### 금액

- 각 연도 VAT·수익·원가·지원금, 입금 항목, 전체 합계에 동일 판정 함수를 적용한다.
- 값 부재/undefined/null/빈칸/false flag는 0원으로 표시하지 않는다.
- 직접 입력한 0(true flag)는 양쪽 모두 0원이다. 다른 칸 입력으로 인접 칸의 입력 상태가 바뀌지 않는다.
- 과거 flag 없는 0은 기존 입력 화면과 같은 “미입력/입력 여부 미기록” 의미로 표시한다. 과거 양수는 기존 UI 정책과 일치시킨다.
- 일부 연도 금액이 비어 있으면 합계·비율을 확정한 것처럼 표시하지 않는다. 기록된 금액의 소계는 소계라고 표시한다.
- 기존 계약금액 보존 시 구성 항목이 덜 입력되었거나 불일치하면 “계산됨”을 표시하지 않는다.
- JLIN 연간490백만/700백만=70%, 전체2450백만/3500백만=70% 유지.
- API snapshot/원장 숫자와 기존 flag를 읽기 단계에서 바꾸지 않는다.

### 서류

- 유효 링크 존재: 제출 링크/링크 열기로 표시, 원문 열에 해당 없음 금지.
- 유효 파일 존재: 파일명/원문 보기로 표시.
- 명시적 해당 없음·미제출 사유: 그 선택/사유를 표시.
- 구형 키 부재: 미기록으로 표시하고 실제 미제출로 단정하지 않는다.
- 새 문서 명시 공란: 응답 필요/미제출 상태를 구형 미기록과 구별한다.
- 링크 입력→해당 없음 해제 시 링크 유지. 선택/조회로 첨부 제거 API가 호출되면 FAIL.
- 탐나는인재 유사 이름 3건은 프로젝트 ID 및 버전으로 구별한다.

### 상태·기존 금액 보완

- KDB 저장 상태 COMPLETED를 숨기거나 날짜로 IN_PROGRESS로 바꾸지 않는다.
- 현재 상태와 체크아웃 노출 근거를 보여주고, 실제 상태 확인이 필요함을 안내한다.
- 수정 경로는 권한 있는 실무자의 현재 프로젝트/초안으로 이동해야 한다. 담당자가 현재 값/근거/수정 영향과 임시저장인지 최종 제출인지 구분할 수 있어야 한다.
- 수정 후 승인 전까지 기존 원장을 보존한다. 요청 버전 충돌이 나면 작성 내용 보존 및 재검토 안내.
- 농산업120백만 vs48백만 구성값의 차액72백만을 원가로 자동 입력하지 않는다.
- 상태/금액 경고는 무엇·왜·누가·어디서·어떻게 고치는지 설명한다. 시스템 용어만 노출하지 않는다.
