## 공통 위험과 해석 한계

1. **외화 표시 오류**: 통화가 USD인데 금액 접미사는 원이다. 36·45·63에서 확인했고 부모가 index11 AVPN에서도 독립 확인했다. 원화 환산 여부/환율은 화면에서 설명되지 않는다. 금액을 임의 환산하거나 currency 값을 변경하지 말고 저장 통화에 따른 표시 계약을 먼저 맞춘다.
2. **다른 범위의 분모**: 39~42는 연도별 계획과 전체0이 충돌한다. 57은 이월금 포함 총액, 59는 다년도 총계로 당해연도 비율을 나누는 문제가 보인다. 메모를 파싱해 숫자 정본을 자동 생성하는 대신 전체/당해연도 범위와 표시 근거를 분리한다.
3. **레거시 미입력 표시**: 오래된 요청 다수에서 실비·연도 재무·실제 인력·참여율 링크·신규 증빙이 없다. UI의 미제출이 실제 파일 유실을 증명하지 않으며, 개인 임시저장에 값이 있는지도 이번 읽기로는 확인하지 않았다.
4. **사업특성/반납 차액**: 팁스의 반납예정 잔여와 자체사업을 모두 일반 계약의 미입력 오류로 취급하면 잘못된 수정이 발생한다. 저장값 보존과 필드별 설명이 필요하다.
5. **정산 완료와 체크리스트 분리**: 종료 체크아웃 미입력과 메모의 입금완료가 공존한다. 어느 한쪽으로 정산 승인/체크아웃 완료를 추정하지 않는다.

## 시각 증거

- index63 GGGI코트디 문서를 열고 계약/재무 영역을 스크롤한 화면에서 USD와3,000원 동시 표시를 CUA 스크린샷으로 직접 확인했다.
- index39 26팁스딥테크 같은 영역에서 전체0원/0%와 연도별70,040,100·35,020,050을 같은 화면에서 직접 확인했다.
- 스크린샷은 이 대화의 도구 결과에 포함되며 별도 이미지 파일로 저장하지 않았다. 원본 계좌번호/다운로드 토큰은 보고서에 복사하지 않았다.

35건의 문서 열람을 완료했지만 35건 모두 입력 화면과 교차 대조한 것은 아니다. 입력 화면 실제 재현과 최종 패치 전후 육안 대조는 부모 작업 결과에 별도로 합친다.

두 대표 스크린샷 확인 후 Chrome 연결이 끊겨 마지막 열린 팁스 문서를 Escape로 닫는 동작은 완료되지 않았다. 이는35건 열람/대표2건 육안 확인 이후 발생했으며 승인·반려·저장 동작은 실행하지 않았다. 추가 UI 검증은 브라우저 재연결 후 진행해야 한다.
