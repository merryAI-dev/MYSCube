- 실제 투입인력 선택칸의 공란과 step3/승인문서의 저장된 인력 요약 차이는 이 하네스의 자체 인력 API 미로딩 영향이다. `ProjectStaffingSection`은 Wizard의 roster prop을 사용하지 않고 별도로 인증된 BFF 조회를 한다. 이 공란을 저장 유실로 집계하지 않는다.

## 인력 명부 재현 보완 및 추가 금액 대조

- `XX-step2-context.png/json` **79개 재캡처 완료**, 인력 명부/역할 조회 fixture 응답 **158건**, 오류 0, 변경 요청 0.
