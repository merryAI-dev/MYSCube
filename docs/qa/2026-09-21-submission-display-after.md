2026-09-21. 운영 저장본 읽기 전용 재현이며 운영 API 변경·저장·승인·배포는 수행하지 않았다. 운영 데이터 자체의 정확성이나 결재 성공을 보장하는 검증이 아니다.

## 변경 범위

- 승인문서·상세패널·편집기 최종 검토의 금액/통화/총수익률/입금계획을 순수 표시 helper로 공유한다.
- 연도별 표에 매출부가세·계산 수익률·재무 확인·잔금 예정 주차를 표시한다. 확인값 미기록과 false, 금액 미입력과 0을 구분한다. 표의 뒤쪽 열은 수평스크롤로 확인하도록 안내한다.
- 제출 당시 상태, 사업관리 폴더, 등록 확인값, 저장된 참여기간·월별 참여율을 승인 화면에 표시한다. 현재 외부 참여율 시트가 제출본과 다를 수 있음을 안내한다.
- 다년도 전체기간 계획만 있는 기존 문서는 연도별 배분을 만들어내지 않는다. 일부 연도 계획이 없으면 전체 합계를 완전한 0으로 취급하지 않는다.
- 계약금액과 항목합계 불일치 또는 비교에 필요한 미입력은 세 검토 화면에 동일한 확인 안내를 표시한다. 제출 차단·자동교정·저장은 추가하지 않는다.
- 미입력 정산 선택값을 임의의 기본 선택으로 표시하지 않는다. 긴 URL/내용은 줄바꿈한다.
