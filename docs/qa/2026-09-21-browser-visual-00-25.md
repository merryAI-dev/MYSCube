# 실제 입력·승인 화면 육안 대조 — 인덱스 0~25

## 검증 범위와 현재 상태

담당 범위는 로컬 브라우저 캡처 manifest의 프로젝트 인덱스 0~25, 총 26개다. 운영에서 읽은 고정 자료를 실제 컴포넌트에 전달한 화면을 대상으로 한다. 운영의 인증·파일 접근·저장·승인 성공을 검증하는 작업은 아니다.

담당 26개 프로젝트의 입력4단계와 승인문서 육안 대조를 완료했다. 아래 결과는 화면 재현에서 확인한 관찰이며 운영 승인·저장 성공 판정과 구별한다.

## 판정 기준

| 대상 | 직접 확인할 사항 | 판정 경계 |
|---|---|---|
| 프로젝트와 버전 | manifest ID, 입력 원본, 승인 요청 원본과 버전 | 이름이 비슷한 프로젝트를 합치지 않음. 원장과 제출본 시점 차이는 오류와 구별 |
| 계약 금액 | 계약 총액, VAT, 수익, 실비, 지원금, 통화, 연도별 합계 | 불일치를 임의로 0 또는 합계로 보정하지 않음 |
| 입금 계획 | 선금·중도금·잔금의 금액과 비율, 연도별 또는 사업 전체 범위 | 연도별 정보가 없을 때 전체 계획이 사라지는지 별도 확인 |
| 상태·체크아웃 | 입력 상태, 승인 상태 표시, 종료 체크아웃과 확인값 | 보이는 상태가 맞다는 판단과 운영상 상태가 맞다는 판단을 분리 |
| 링크·파일 | 구글 링크, 제출 파일명, 첨부 종류와 미제출 문구 | 버튼 존재는 실제 파일 접근 성공을 의미하지 않음 |
| 나머지 필드 | 기본정보·기간·인력·메모·확인값 | DOM에 있는 값과 사람이 읽을 수 있는 값을 분리 |
| 캡처 완전성 | 입력 4단계 및 승인문서의 전체 내용이 읽히는 크기로 존재 | 잘린 하단, 축소되어 읽을 수 없는 숫자는 미검증 |

## 공통 발견과 조치 제안

1. **동일 요약 안의 서로 다른 금액 출처**: 02·04·08·10·16·18·23의 4단계 연도별 서술은 입금0으로 보이지만, 바로 아래 입금카드와 승인 연도표에는 금액이 있다. 단일 연도라도 실제 저장된 입금계획을 동일한 projection으로 표시해야 한다. 값이 없으면 미등록으로 표시하고 0으로 대체하지 않는다.
2. **금액 경고의 비대칭**: 여러 입력 화면에 계약총액/구성합 불일치가 보이나 승인문서에는 같은 값만 보이고 차이 설명이 없다. 자동 합계 덮어쓰기가 아닌 현재총액·구성합·차이·확인주체를 양쪽 동일하게 보여야 한다. 과거 저장 또는 승인 당시에 검증을 우회했다는 인과는 이 읽기 전용 캡처만으로 확정하지 않는다.
3. **비율의 범위**: 25에서 연도70%와 사업전체16%는 다른 분모라 산술상 양립한다. 양쪽에 연도/사업전체 범위와 분모를 명시해야 한다. 09의70.0%와70%미만 동시표시는 반올림 경계 표시를 조정해야 한다.
4. **승인 상태의 내부모순**: 13의 철회가 검토대기로 나타난다. 17·19·20·24의 버전없는 등록요청은 본문 승인완료와 인장칸 검토대기가 동시에 보인다. 미지정 결재자를 임의 승인자로 채우지 말고 이력 부재와 상태를 구분한다.
5. **표시범위 누락**: 승인 연도표에는 VAT·수익률이 없고 사업관리폴더도 노출되지 않는다. 입력에서 볼 수 없는 승인 잔금메모·참여조건·등록메모도 있다. 양쪽 모든 필드의 동일성이 성립한다고 볼 수 없다.
6. **빈값의 의미**: 입력0/승인`-`, 체크해제/미입력, 정산기준 미선택/정산없음이 혼재한다. 미입력·0·해당없음·아니오를 공통 계약으로 구분한다.
7. **가독성**: 입력4단계 긴 폴더/참여율 링크가 카드영역을 넘어 인접 첨부명과 겹치는 예가 있다. 원문URL을 그대로 펼치는 대신 의미있는 링크라벨과 줄바꿈을 적용할 수 있다.

## 검증 완료 범위와 남은 한계

26개 × 입력4단계·승인문서 = **130장 직접 육안 확인**을 완료했다. 실제 기본 모달 뷰포트00·13·17·25도 추가로 직접 확인했다(4장). 13의철회/대기,17의승인완료/인장대기 모순은 기본뷰포트에서도 읽힌다. 전체확장 캡처를 기본 모달 한 화면으로 오해하지 않는다.

- 이 검증은 실제 저장 자료의 로컬 브라우저 재현이다. 운영 서비스의 권한별 진입, 최종제출, 승인 실행, 승인후 재조회, 결산반영은 수행하지 않았다. 사진에 버튼이 존재한다고 동작 성공을 선언하지 않는다.
