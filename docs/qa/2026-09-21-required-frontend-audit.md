## 원가 누락 실제 재현
새 2026 단년도 draft에서 원가를 건드리지 않고 수익만 100 입력하고 임시저장. 저장 콜백 결과 totalActualCost=0, financialInputFlags.totalActualCost=true, 모든 5개 플래그 true, row.confirmed=false. JSON/스크린샷 finance-empty.* 참조.

## 권고
연도별 금액은 숫자와 명시 입력 상태를 함께 보관. 공란을 0으로 확인처리하지 말고, 사용자가 직접 입력한 0은 유효값으로 허용. 표시·최종 제출·BFF는 같은 규칙을 사용하고 임시저장은 미완성 허용. 기존 제출/승인에 새 필수조건 소급 적용 금지. 기존 필드 누락은 자동 보정 없이 안내. 기본 선택값과 명시선택의 정책은 별도 취급하며 기존 주월정산 설정 자동 변경 금지.
