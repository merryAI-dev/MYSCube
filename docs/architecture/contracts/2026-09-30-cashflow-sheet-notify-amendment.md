# 현금흐름 시트 규칙 불일치 — 막지 않고 알린다 (계약 개정)

**날짜:** 2026-09-30
**상태:** 확정 · 구현됨 (브랜치 `merryAI-dev/discuss-spring-backend-split`)
**개정 대상:** [수식 검증 계약 2026-07-28](./2026-07-28-cashflow-formula-validation-contract.md) §4.6, §7, Phase 4
**근거 결정:** [검사 범위 격리 계획 §0](../2026-09-30-settlement-validation-scope-plan.md) 결정 1~7
**바뀌지 않는 것:** 좌표 계약(`server/bff/cashflow-coordinates.mjs`), 양식이 다르면 반영하지 않는 원칙, EMPTY/ZERO 구분, 결재 중·마감된 월 보호, 권한·동시 수정·해시 검증

## 원칙

시트 형식·검산 규칙이 안 맞는 것은 **처리 전체를 멈추지 않는다.** 문제 부분만 빼거나 기록한 뒤 진행하고, 어느 칸·어느 기록이 무엇이 문제인지 사용자에게 알린다. 막는 것은 데이터 보호 장치뿐이다. 값을 만들어 내지 않는다.

## 개정 조항

| 7/28 조항 | 이전 | 개정 |
|---|---|---|
| §4.6 입금 예정 합계(`BS9`), 세금계산서·입금일 형식 | 검산 대상. 불일치·형식 오류가 월결산 차단 사유가 됨 | 검산은 유지하되 **표시용**. 월결산 차단 사유가 아니다(알림) |
| Phase 4 "쓰기 전 `409 cashflow_formula_mismatch_confirmation_required`, 사용자가 `그래도 현재 시트값 반영`을 골라야 재시도" | 확인 단계 필수 | **확인 단계 없음.** 새 반영 요청은 불일치를 수락한 것으로 보낸다. 불일치 목록(연월·주차·구분·항목·시트 값·엔진 계산 값·셀)은 반영 결과(`formulaMismatches`)로 알린다. 배포 전에 멈춘 반영을 이어서 할 때는 그때 요청 그대로 판정한다 |
| §7 "불일치는 반영은 허용하고 결산은 차단" | 문서상 결산 차단 | 이번 개정 전부터 코드는 **경고**(`SHEET_CALCULATION_MISMATCH`)였다. 그 동작을 유지한다. 결산 화면이 불일치 칸을 보여 준다 |

## 새로 정한 동작

| 영역 | 동작 |
|---|---|
| 월결산 검증 | `SHEET_VALUE_INVALID`, `SHEET_CONTROL_TOTAL_*`, `SHEET_CALCULATION_CHECK_MISSING/VALUE_INVALID`는 경고. 결산 대상 월의 160셀이 불완전하면 **그 달만** 결산 보류(`SHEET_MONTH_INCOMPLETE`, 기존 유지) |
| 시트 불러오기 실패 | 양식·탭·주차 범위·주별 연도 규칙으로 거절되면 이미 고정한 값은 `FRESH` 유지, `lastRefreshError`만 기록. 월결산은 `SHEET_LAST_REFRESH_FAILED`로 알림. 통신 오류·설정 변경은 기존대로 `STALE` |
| 반영 검토 | 형식 때문에 못 읽는 첫 달과 그 이후 달, 주별 연도 이후 연간 값은 이번 반영에서 뺀다(`excludedMonths`, `excludedYears`, `sheetScope`). 결재 중 회차는 기존대로 run 전체 차단 |
| 연간 값 불완전 | 주별 연도 **이후** 연도는 그 연도만 건너뜀. **이전** 연도는 1월 기초 잔액 근거라 기존대로 차단 |
| 반영 직전 수식 검증 | 검토 단계가 정한 범위(`sheetScope`)만 근거로 쓴다 |
| 주차 기록이 표준 형태가 아님 | 반영 저장은 연간 원장 보호를 위해 기존대로 차단. 오류 코드 `cashflow_week_document_invalid`와 연월·주차·문제를 담아 알림. 주정산 완료는 대상 주 + 16주 창 밖이면 막지 않고 알림 |
| 주정산 Projection 16주 누락 | 막지 않음. 누락 건수·증거 해시는 완료 기록에 남기고 응답(`notices`)으로 알림 |
| 오류 표시 | 서버가 사람에게 쓴 한국어 문구를 그대로, 단계(① 불러오기 · ② 반영 검토 · ③ 반영 · ④ 저장)와 오류 코드·요청 ID를 붙여 보여 준다. 정산 엔진의 영어·내부 메시지는 기존대로 가린다 |
